Cloud Providers

Optional, and off until you deliberately turn one on. A cloud provider is only asked about files the local models could not place, and it receives the same redacted description they do — filenames, sizes and durations, never the file itself and never its path. All three charge for use; LibrAIry does not resell anything, you are billed by them directly.

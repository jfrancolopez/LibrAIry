If a path is wrong

The host paths come from HOST_LIBRARY_DIR, HOST_INBOX_DIR, and HOST_QUARANTINE_DIR in the container environment. If one of them reads (not mapped) or points somewhere stale, update it and restart the container — Settings → Storage paths has a helper that writes the lines for you.

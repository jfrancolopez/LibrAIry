What LibrAIry has learned

Patterns built from decisions you made and committed.

{# The whole point of this page is that nothing here is a secret. A suggestion in Review should never be the first time somebody hears that a pattern exists, and turning one off should not require finding a file it happens to fire on. #}

Nothing on this page approves anything, files anything or moves a file. When one of these matches a file in Review, LibrAIry offers the answer and you decide — exactly as before. That is as true of a rule you wrote down as of a habit LibrAIry noticed: a rule fills an answer in, and never takes a decision.

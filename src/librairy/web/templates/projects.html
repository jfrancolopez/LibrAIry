Projects

Files that belong together, wherever they live.

{# The distinction, said once and said first. `Projects/` is a folder files are moved into; a Project is a view across everything you already have, and the two have never been the same thing. See docs/ui-vocabulary.md. #}

A Project is a tag you promoted. Anything carrying that tag is part of it from the moment the tag is read. Its files stay exactly where they are — nothing is moved, copied or renamed, and a Project is not the Projects/ folder in your library, which is a filing destination like any other.
